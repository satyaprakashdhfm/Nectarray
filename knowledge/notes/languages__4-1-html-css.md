# Complete UI/UX Vocabulary Guide

## 1. Interface Elements

### **Buttons & Controls**
- **Primary Button** - Main action button (usually highlighted)
- **Secondary Button** - Alternative or less important action
- **CTA (Call-to-Action)** - Button encouraging user action
- **Toggle** - Switch between two states (on/off)
- **Checkbox** - Multiple selection option
- **Radio Button** - Single selection from group
- **Switch** - Binary on/off control
- **Slider** - Range input control
- **Stepper** - Increment/decrement control
- **Floating Action Button (FAB)** - Circular button for primary actions

### **Navigation Elements**
- **Navbar/Navigation Bar** - Top horizontal navigation
- **Sidebar** - Vertical navigation panel
- **Breadcrumbs** - Path showing user's location
- **Tabs** - Content section switchers
- **Menu** - List of options or actions
- **Hamburger Menu** - Three-line collapsible menu icon
- **Dropdown** - Expandable list of options
- **Pagination** - Page navigation controls
- **Back Button** - Return to previous page/state

### **Input Fields & Forms**
- **Text Field** - Single-line text input
- **Text Area** - Multi-line text input
- **Search Bar** - Text input for searching
- **Form** - Collection of input fields
- **Label** - Text describing input field
- **Placeholder** - Hint text in empty input
- **Validation** - Input error/success feedback
- **Autocomplete** - Suggested input completion
- **Date Picker** - Calendar input control
- **File Upload** - File selection interface

## 2. Layout & Structure

### **Layout Terms**
- **Grid** - Column-based layout system
- **Container** - Wrapper for content sections
- **Row** - Horizontal grouping of elements
- **Column** - Vertical division of space
- **Section** - Distinct content area
- **Header** - Top area of page/component
- **Footer** - Bottom area of page/component
- **Sidebar** - Side panel for additional content
- **Main Content Area** - Primary content space
- **Hero Section** - Large banner/intro area

### **Spacing & Positioning**
- **Margin** - Space outside an element
- **Padding** - Space inside an element
- **Gutter** - Space between grid columns
- **White Space** - Empty space around elements
- **Leading** - Space between lines of text
- **Tracking** - Space between letters
- **Alignment** - Element positioning (left, center, right)
- **Spacing System** - Consistent spacing scale
- **Baseline** - Invisible line text sits on

### **Visual Hierarchy**
- **Z-Index** - Layering order of elements
- **Hierarchy** - Order of importance in design
- **Focal Point** - Area that draws attention
- **Visual Weight** - How much attention an element attracts
- **Contrast** - Difference between elements
- **Emphasis** - Making elements stand out

## 3. Content Elements

### **Text & Typography**
- **Heading/Header** - Title text (H1, H2, H3, etc.)
- **Body Text** - Main readable content
- **Caption** - Small descriptive text
- **Subheading** - Secondary title
- **Label** - Identifying text for elements
- **Link** - Clickable text connection
- **Font Family** - Typeface used
- **Font Weight** - Thickness of text (bold, light)
- **Font Size** - Text size measurement
- **Line Height** - Vertical space between text lines

### **Media Elements**
- **Image** - Static visual content
- **Icon** - Small symbolic graphic
- **Avatar** - User profile picture
- **Thumbnail** - Small preview image
- **Gallery** - Collection of images
- **Carousel** - Rotating content slider
- **Video Player** - Media playback interface
- **Background Image** - Image behind content

### **Data Display**
- **Card** - Contained information block
- **List** - Vertical arrangement of items
- **Table** - Structured data in rows/columns
- **Chart/Graph** - Visual data representation
- **Badge** - Small status indicator
- **Tag** - Categorization label
- **Tooltip** - Hover information popup
- **Progress Bar** - Task completion indicator
- **Loading Spinner** - Processing indicator

## 4. Interactive Elements

### **Feedback & States**
- **Hover State** - Element appearance on mouse over
- **Active State** - Element being clicked/pressed
- **Focus State** - Element selected for keyboard input
- **Disabled State** - Non-interactive element
- **Loading State** - Element processing action
- **Error State** - Problem indication
- **Success State** - Positive feedback
- **Empty State** - No content available message

### **Overlays & Modals**
- **Modal** - Popup dialog box
- **Overlay** - Layer covering main content
- **Popup** - Small informational window
- **Dropdown** - Expandable options list
- **Drawer** - Sliding panel interface
- **Lightbox** - Image/content viewer overlay
- **Toast/Snackbar** - Brief notification message
- **Alert** - Important information popup

### **Scroll & Movement**
- **Scroll Bar** - Content navigation bar
- **Infinite Scroll** - Continuous content loading
- **Parallax** - Background movement effect
- **Sticky Element** - Fixed position while scrolling
- **Smooth Scroll** - Gradual page movement
- **Scroll Indicator** - Progress through page

## 5. Design Principles & Concepts

### **Visual Design**
- **Color Palette** - Set of colors used
- **Brand Colors** - Organization's official colors
- **Accent Color** - Highlighting color
- **Neutral Colors** - Grays, whites, blacks
- **Gradient** - Color transition effect
- **Opacity** - Element transparency level
- **Shadow** - Drop shadow effect
- **Border** - Element edge line
- **Corner Radius** - Rounded corner amount

### **Layout Principles**
- **Responsive Design** - Adapts to different screen sizes
- **Mobile-First** - Design starting with mobile
- **Breakpoint** - Screen size change point
- **Fluid Layout** - Flexible width design
- **Fixed Layout** - Static width design
- **Above the Fold** - Visible without scrolling
- **F-Pattern** - Common reading pattern
- **Rule of Thirds** - Composition guideline

### **User Experience Concepts**
- **User Flow** - Path users take through interface
- **User Journey** - Complete user experience map
- **Wireframe** - Basic layout structure
- **Prototype** - Interactive design mockup
- **Persona** - User archetype representation
- **Use Case** - Specific user scenario
- **Pain Point** - User frustration area
- **Conversion** - Desired user action completion

## 6. Technical Terms

### **Development Concepts**
- **Component** - Reusable interface element
- **Framework** - Code structure foundation
- **Library** - Collection of pre-written code
- **API** - Application Programming Interface
- **Frontend** - User-facing interface
- **Backend** - Server-side functionality
- **Database** - Information storage system
- **Responsive Breakpoints** - Design adaptation points

### **Performance & Accessibility**
- **Loading Time** - Page load duration
- **Accessibility (A11y)** - Design for all users
- **Screen Reader** - Assistive technology
- **Alt Text** - Image description for accessibility
- **Contrast Ratio** - Color accessibility measure
- **Focus Order** - Keyboard navigation sequence
- **ARIA Labels** - Accessibility descriptions
- **Semantic HTML** - Meaningful code structure

## 7. Process & Methodology

### **Design Process**
- **Design System** - Consistent design standards
- **Style Guide** - Visual standards document
- **Brand Guidelines** - Brand application rules
- **Mockup** - Static design representation
- **High-Fidelity** - Detailed, realistic design
- **Low-Fidelity** - Basic, rough design
- **Iteration** - Design refinement cycle
- **A/B Testing** - Comparing design versions

### **Research & Testing**
- **User Testing** - Observing user interactions
- **Usability Testing** - Interface ease-of-use testing
- **Heat Map** - User interaction visualization
- **Analytics** - User behavior data
- **Conversion Rate** - Success action percentage
- **Bounce Rate** - Single-page visit percentage
- **User Feedback** - Direct user input
- **Stakeholder** - Project decision maker
