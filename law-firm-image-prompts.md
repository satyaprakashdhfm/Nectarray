# Law firm animation: 20 image prompts

For the Gemini app (free). 4 scenes, 5 images each.

## How to use

1. Start a **new chat for each scene**.
2. Send **Image 1** of the scene. Download the result.
3. For Images 2 to 5, send the prompt **in the same chat**, so Gemini edits the image it just made. If it doesn't, attach the previous image and send the prompt again.
4. Save each image with the file name shown (for example `1-1.png`).
5. If an image changes the camera angle, the background, the art style or someone's face, ask again:
   "Keep everything exactly as in the previous image, only change what I asked."
6. Put all 20 files in one folder and send me the folder path.
