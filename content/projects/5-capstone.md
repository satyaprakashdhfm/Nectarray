Everything from the four projects before this, in one place, solving one problem you choose. A study assistant over your own notes; a support agent over a product's documentation; a research assistant over a set of papers.

**It must have**

- **Retrieval** over a real corpus, with the evaluation from Project 3
- **An MCP server** exposing at least two tools the agent genuinely needs
- **An agent** that decides which to use, capped and guarded
- **Memory** — session history that survives a restart, and at least one fact carried between sessions
- **An evaluation set** of 15+ cases checking both the answer *and* which tools were called

**And a README that covers**

- Architecture, with a diagram of what calls what
- What it costs per conversation, measured, not estimated
- The failure modes you found and what you did about each
- What you would fix next, and why that first

This is the one to show people. Treat the README as the deliverable and the code as the evidence.
